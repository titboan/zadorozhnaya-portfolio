# Zadorozhnaya Portfolio

Сайт-портфолио графического дизайнера Zadorozhnaya.

🔗 [zadorozhnaya-portfolio.vercel.app](https://zadorozhnaya-portfolio.vercel.app)

## Стек
React + Vite, обычный CSS (без Tailwind), без бэкенда.

## Запуск
```bash
npm install
npm run dev      # localhost:5173
npm run build    # сборка для деплоя
npm run preview  # посмотреть сборку локально
```
