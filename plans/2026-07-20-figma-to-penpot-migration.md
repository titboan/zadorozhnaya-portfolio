# План: переход с Figma на Penpot

Статус: в работе

## Почему

Figma MCP на бесплатном (Starter) тарифе ограничен 6 вызовами чтения в месяц — это упирается в потолок почти сразу и не лечится аккуратными запросами. REST API на том же тарифе тоже сильно порезан (см. `retrospectives/2026-06-18_figma-export-rate-limit.md`).

Penpot — бесплатная и без лимитов альтернатива:
- Inspect-панель (CSS/SVG/HTML значения) встроена бесплатно всем, без платного Dev Mode
- Нативный формат SVG — меньше расхождений при переносе в CSS
- Официальный MCP-сервер есть, но подключить его в claude.ai/Claude Code проще через CLI (`claude mcp add`) или self-host — Penpot не входит в каталог коннекторов claude.ai по умолчанию (проверено: в `SearchMcpRegistry` нет)

## Часть 1 — то, что делает Боря (дизайн)

- [ ] Зарегистрироваться на penpot.app (бесплатно, облачный вариант — self-host не нужен)
- [ ] Перенести дизайн-файл `rA5AGt3zuM05YM7lzS0CoC`:
  - Экспортировать из Figma как `.fig` (Figma → File → Save local copy)
  - Импортировать в Penpot (есть встроенный импортер `.fig` файлов)
  - Визуально сверить с оригиналом — импорт может потерять нюансы (blend modes, эффекты), особенно то что уже описано в `ai-clone/feedback/figma-passthrough-blend-mode.md`
- [ ] Прислать мне ссылку на новый Penpot-файл

## Часть 2 — то, что делаю я (код/доки), после того как файл появится в Penpot

- [ ] Обновить `.claude/skills/figma-workflow.md` → переименовать в `penpot-workflow.md`, вписать реальные project/file id и путь работы через Inspect-панель

## Часть 3 — рабочий процесс дальше (по умолчанию, без MCP)

1. Ты открываешь нужный фрейм в Penpot → Inspect-панель → копируешь CSS/размеры/цвета
2. Присылаешь мне текстом (или файлом) — так же, как уже делали с мобильной вёрсткой по Figma CSS-экспорту
3. Я верстаю по присланным значениям, без единого обращения к внешнему API — лимитов нет в принципе

## Часть 4 — опционально, если понадобится программный доступ

Если ручной Inspect-копипаст всё равно окажется утомительным — можно подключить `penpot-mcp` (github.com/penpot/penpot-mcp) как кастомный MCP-сервер. Это делается не через настройки коннекторов claude.ai (Penpot там не числится), а либо через `claude mcp add` в Claude Code CLI на твоей машине, либо через админа воркспейса, если аккаунт командный. Технически потребует генерации Access Token в Penpot (Settings → Access Tokens). Пока не делаем — сначала проверяем, хватает ли ручного Inspect-потока.

## Открытые вопросы

- Насколько хорошо `.fig` импортёр Penpot сохранит текущий файл (эффекты, blend modes, компоненты) — узнаем только на практике
- Если импорт много потеряет — альтернатива: пересоздать в Penpot только то, что реально нужно доделать (кейсы), а старый Figma-файл оставить как архив для уже реализованных секций
