## Часть 4 — Figma → Lunacy, локально через VS Code (снимает лимит в 6 запросов/месяц навсегда)

**Решение:** Lunacy (Icons8) вместо Penpot — бесплатный десктоп-редактор (Win/Mac/Linux), нативный импорт `.fig`, и, что решающее, официальный MCP-сервер, который работает локально на компьютере Бори и создан с прицелом именно на связку с Claude. Работает, потому что Боря делает это на своей машине, где уже есть VS Code.

**Кто делает:** Боря — установка и перенос дизайна, Клод — доки и работа с MCP после подключения

1. Боря, установка (один раз):
   - [ ] Установить Lunacy (icons8.com/lunacy) — бесплатно, без подписки
   - [ ] Клонировать репозиторий `zadorozhnaya-portfolio` локально, открыть в VS Code
   - [ ] Установить Claude Code (расширение VS Code или CLI через встроенный терминал)
   - [ ] Настроить свой git-доступ к GitHub локально (в этой облачной сессии он настроен отдельно и не переносится автоматически)
2. Боря, перенос дизайна:
   - [ ] В Figma → Share → скопировать ссылку на файл `rA5AGt3zuM05YM7lzS0CoC`
   - [ ] В Lunacy — `Ctrl/Cmd+V`, вставить ссылку → импорт `.fig`
   - [ ] Проверить именно эффект Rectangle56 (frosted glass, blur+opacity) — известное ограничение импорта: если блюров несколько, переносится только верхний. См. `ai-clone/feedback/figma-passthrough-blend-mode.md`
   - [ ] Включить в Lunacy MCP/LLM-интеграцию (Settings → LLM Integration → Edit Config)
3. Боря, подключение MCP к Claude Code:
   - [ ] Скопировать конфиг из Lunacy, добавить в `claude_desktop_config.json` (Claude Desktop) или через `claude mcp add` (Claude Code CLI в терминале VS Code)
   - [ ] Перезапустить Claude — дальше локальная сессия видит выделенные объекты в Lunacy в реальном времени
4. Клод (в локальной сессии, после подключения):
   - [ ] Обновить `.claude/skills/figma-workflow.md` → `lunacy-workflow.md`
   - [ ] Обновить раздел «Figma» в `CLAUDE.md` на «Lunacy» + путь к локальному файлу
   - [ ] Не удалять данные о старом Figma-файле, пока не подтверждено что весь нужный контент (кейсы, ассеты) перенесён

**Важно:** эта часть плана работает только в локальной сессии Claude Code на компьютере Бори (через VS Code) — у текущей облачной сессии нет доступа к её экрану и локально запущенным приложениям вроде Lunacy.

**Запасной вариант:** если импорт `.fig` заметно потеряет эффекты — Penpot (облачный, тоже бесплатный, с бесплатной Inspect-панелью для ручного CSS-копипаста) остаётся резервным путём без необходимости что-то переустанавливать.

## Открытые вопросы

- Насколько хорошо `.fig`-импортёр Lunacy сохранит текущий файл — известное ограничение: несколько blur-слоёв схлопываются в один, компоненты становятся инстансами, star/polygon превращаются в обычные path. Прототипирование не переносится, но оно нам не нужно
- Если импорт заметно потеряет эффекты (особенно Rectangle56) — переходим на запасной вариант Penpot вместо пересоздания дизайна с нуля
