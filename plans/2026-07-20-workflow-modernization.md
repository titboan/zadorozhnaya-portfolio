# План: модернизация workflow (Figma-лимиты, ручная работа, инструменты)

Статус: в работе

## Контекст

Отправная точка — Figma MCP на бесплатном тарифе ограничен **6 вызовами чтения в месяц** (не вопрос аккуратности запросов, это жёсткая квота), плюс REST API так же порезан (см. `retrospectives/2026-06-18_figma-export-rate-limit.md`). Заодно разобрали, какие ещё бесплатные инструменты закрывают повторяющуюся ручную работу (тяжёлые картинки из Figma, отсутствие проверки деплоя).

Принцип: Боря — дизайн, Клод — код. Всё, что можно снять с Бори автоматизацией на моей стороне, снимаем; всё, что требует его аккаунта/выбора — явно помечено ниже.

## Часть 4 — Figma → Penpot (снимает лимит в 6 запросов/месяц навсегда)

**Кто делает:** Боря — перенос дизайна, Клод — доки после переноса

1. Боря:
   - [ ] Зарегистрироваться на penpot.app (бесплатно, облачный вариант)
   - [ ] Экспортировать текущий файл `rA5AGt3zuM05YM7lzS0CoC` из Figma как `.fig`, импортировать в Penpot
   - [ ] Визуально сверить с оригиналом — импорт может не сохранить нюансы (blend modes, эффекты — см. `ai-clone/feedback/figma-passthrough-blend-mode.md`)
   - [ ] Прислать ссылку на новый Penpot-файл
2. Клод, после получения ссылки:
   - [ ] Обновить `.claude/skills/figma-workflow.md` → `penpot-workflow.md`
   - [ ] Обновить раздел «Figma» в `CLAUDE.md` на «Penpot» + ссылку
   - [ ] Не удалять данные о старом Figma-файле, пока не подтверждено что весь нужный контент (кейсы, ассеты) перенесён

**Рабочий процесс дальше (без MCP, работает сразу после переноса):**
Боря открывает фрейм в Penpot → Inspect-панель (бесплатна у всех, аналог платного Figma Dev Mode) → копирует CSS/размеры/цвета → присылает текстом → Клод верстает. Лимитов на чтение нет в принципе.

**Опционально, если ручной копипаст надоест:** подключить `penpot-mcp` (github.com/penpot/penpot-mcp) как кастомный MCP-сервер — не через настройки коннекторов claude.ai (Penpot там не числится), а через `claude mcp add` в CLI или админа воркспейса. Требует Access Token из Penpot. Не делаем, пока не проверили, что хватает ручного Inspect-потока.

## Открытые вопросы

- Насколько хорошо `.fig`-импортёр Penpot сохранит текущий файл (эффекты, blend modes, компоненты) — узнаем только на практике
